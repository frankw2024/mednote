# MedNote Native Apps

Native mobile clients for MedNote — AI-powered medical visit recording.

| Platform | Path | Build from Windows? |
|----------|------|---------------------|
| **Android** | [`android/`](android/) | ✅ Yes — Android Studio |
| **iPhone / iPad** | [`ios/`](ios/) | ❌ Needs Mac/Xcode |

Both apps mirror the web phone-call workflow:

- **One-tap call visit** — start recording, open phone dialer, speakerphone during call
- **Import audio** — Voice Memos / recorder files as fallback
- **In-person recording** — clinic visits without a phone call
- **AI pipeline** — Groq Whisper + Gemini/Groq summary & item extraction
